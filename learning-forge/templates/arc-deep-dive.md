# Deep dive arc (10–20 min, default 660 s) — flagship content

Structure: 3–4 chapters, each a compressed lesson arc:
  chapter = [chapter_hook(8–12 s) → beats(2–4 × 30–45 s) → chapter_payoff(15–20 s)]
Global:
  - opens with the lesson's Scene01_Hook + Scene02_Map (15 s)
  - two voices throughout: main explains, second plays the skeptic/student
    (second voice on ≥1 scene per chapter)
  - ≥2 "live demo" beats where code visibly executes (counters move, logs appear)
  - one open loop per chapter, ALL closed in the final recap chapter
  - final chapter: recap(30 s) + trap-revisited(20 s) + cta(5 s)

Typical 660 s: 13–16 scenes. Target cv > 0.2 across scenes.
Use `--quality qh` for delivery. Chapters get `chapter_title` in script.json.
