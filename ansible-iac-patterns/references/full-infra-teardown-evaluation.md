# Full Infra Teardown & Rebuild — Pitfalls & Recovery Guide

## Session Date: 2026-08-02

This file documents critical findings from a full infrastructure teardown (VM preserved, all services destroyed) and rebuild attempt via Ansible.

## Critical Failures Discovered

### 1. Ansible `***` Redaction Corrupts Rendered .env Files

**Symptom:** All rendered `.env` files on the VM contain literal `***` instead of Jinja2 `{{` for vault variable references.

```bash
# BROKEN output:
KEYCLOAK_ADMIN_PASSWORD=*** keycloak_admin_password | default('CHANGE_ME_IN_VAULT') }}
KC_DB_PASSWORD=*** keycloak_db_password | default('CHANGE_ME_IN_VAULT') }}
```

**Root cause:** The `.env.j2` template source files had `{{` replaced with `***` from a prior Ansible log redaction or content scan (grep). The `ansible.builtin.template` module passed `***` through literally — the remote `.env` file gets literal `***` instead of Jinja2 expressions.

**Affected templates:** `roles/{keycloak,lightserp,minio,searxng,pagezen,gitea}/templates/.env.j2`

**Fix applied:**
```bash
# Check which templates have *** instead of {{
grep -l '\*\*\*' roles/*/templates/.env.j2 2>/dev/null

# Verify on disk (NOT via grep — use cat or head):
cat roles/keycloak/templates/.env.j2 | head -5

# Fix: restore {{
sed -i '' 's/=\*\*\* /={{ /g' roles/keycloak/templates/.env.j2
```

**Prevention:** Never use `grep` to inspect `.env.j2` templates — grep redacts `{{` as `***`. Use `cat` or `head` or `read_file` tool instead.

### 2. Cloudflare Tunnel Credentials NOT in Backup

**Symptom:** After teardown, cloudflared fails to start. No `iacgenie-tunnel.json` exists anywhere.

**Root cause:** The `iacgenie-tunnel.json` credentials file is generated by `cloudflared tunnel create` and stored ONLY on the local machine. It was NOT in git, NOT in backups.

**Recovery path (must be manual):**
```bash
cloudflared tunnel login           # creates ~/.cloudflared/cert.pem
cloudflared tunnel create iacgenie-tunnel  # creates the credentials JSON
cp ~/.cloudflared/iacgenie-tunnel.json /etc/cloudflared/iacgenie-tunnel.json
systemctl start cloudflared
```

**Prevention:** Export tunnel credentials to a password manager or encrypted backup immediately after creation.

### 3. Missing .env.<service> Files on VM

**Symptom:** Only 4 of 10 expected `.env.<service>` files exist after teardown:
- ✅ `.env.postgres`, `.env.keycloak`, `.env.lightserp`, `.env.pi.bak`
- ❌ `.env.minio`, `.env.openbao`, `.env.redis`, `.env.searxng`, `.env.nsqd`, `.env.gitea`, `.env.pagezen`

**Impact:** docker-compose-generator's env-merge has gaps — containers start with blank/missing env vars.

**Fix:** Re-run Ansible services playbook after fixing `.env.j2` templates so they render correctly.

### 4. Image Tag Mismatch Between Compose Template and Local Images

| Compose Expected | Local Image | Status |
|-----------------|-------------|--------|
| `searxng/searxng:1.0.0` | `searxng/searxng:latest` | ❌ 1.0.0 not on Docker Hub |
| `nsqio/nsq:v1.3.0` | `nsqio/nsq:latest` | ❌ v1.3.0 not on Docker Hub |
| `minio/minio:RELEASE...` | `minio/minio:latest` | ❌ tag not found |
| `mkanavi/lightserp-api:latest` | `lightserp-lightserp-api:latest` | ❌ name mismatch |

**Fix:** Update compose template to match local images. **Verification:** `ssh user@vm 'docker images --format "table {{.Repository}}\t{{.Tag}}"'` before any rebuild.

### 5. Cloudflare Config YAML — `*` Wildcard is a YAML Alias

```yaml
# BROKEN — * triggers YAML alias syntax error
hostname: *.iacgenie.com
service: http://*:80

# FIXED — quote the *
hostname: "*.iacgenie.com"
service: "http://*:80"
```

## Recovery Playbook (Order Matters)

1. **Extract data backups** — `tar xzf /opt/backup/*/minio-data.tar.gz -C /home/mkanavi/docker/iacgenie/`
2. **Fix Ansible templates** — ensure `.env.j2` has `{{` not `***`
3. **Fix image tags** in compose template to match local images
4. **Fix Cloudflare config** — remove duplicate ExecStart from systemd, fix YAML `*` quoting
5. **Generate Cloudflare tunnel credentials** (manual step)
6. **Run Ansible services playbook** — deploys all .env files and generates docker-compose.yml
7. **Deploy Docker containers:** `docker compose -p iacgenie up -d`
8. **Restore databases:** `docker exec -i iacgenie_postgres psql -U postgres < /opt/backup/*/pg-dump.sql`
9. **Start cloudflared:** `systemctl start cloudflared`
10. **Verify all services**

## Pre-Teardown Checklist

Before `docker compose down -v`:
- [ ] Cloudflare tunnel credentials exported to password manager
- [ ] All `.env.j2` templates verified to have `{{` (not `***`)
- [ ] Local Docker images tagged and named to match compose template
- [ ] `.env` files backed up with real secrets
- [ ] Database dumps taken
- [ ] MinIO/Gitea data tarred
- [ ] Cloudflare config verified (YAML syntax, credentials path)
- [ ] Ansible templates cleaned and committed
