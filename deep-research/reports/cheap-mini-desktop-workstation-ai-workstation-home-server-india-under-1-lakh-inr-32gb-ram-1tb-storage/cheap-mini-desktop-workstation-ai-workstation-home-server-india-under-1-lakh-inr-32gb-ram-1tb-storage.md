## Key Considerations for Home Server / AI Workstation

### Power Consumption (24/7 running)
- **Mini PCs:** 15-35W idle → ~₹500-1,200/month electricity
- **Refurbished Tiny PCs:** 20-40W idle → ~₹700-1,400/month
- **Rack Servers:** 80-150W idle → ~₹2,800-5,200/month

### Noise
- **Mini PCs:** 20-30 dB (silent)
- **Tiny PCs:** 25-35 dB (near-silent)
- **Rack Servers:** 40-55 dB (loud — not bedroom-friendly)

### Best OS for Homelab
- **Proxmox VE** — Best for virtualization (KVM + LXC)
- **Ubuntu Server** — Best for Docker containers
- **TrueNAS** — Best for NAS/storage
- **CasaOS** — Easiest for beginners

### Recommended Homelab Stack
```

├── Ubuntu Server (Docker host)
```
