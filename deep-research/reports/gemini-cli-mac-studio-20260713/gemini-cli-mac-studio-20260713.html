🤖 Gemini CLI on Mac Studio

Comprehensive Research Report — July 13, 2026

Mac Studio M4 · google-genai v2.11.0 · GEMINI_API_KEY

📋 Executive Summary

  • Google's Gemini API is API-first — no native CLI binary
  • Python SDK google-genai is the primary interface
  • 35+ models: text, image (Imagen 4.0), video (Veo 3.1), audio, embedding
  • Installed on Mac Studio M4 via uv pip install google-genai
  • API key in ~/.bash_profile (must read from file)

⚙️ Installation & Setup

1. Install SDK

uv pip install google-genai

2. Set API Key

export GEMINI_API_KEY="..." in ~/.bash_profile

3. Initialize Client

client = genai.Client(api_key=key)

  • chats.create — Multi-turn conversation
  • files.upload — Upload any file (PDF, audio, video, images)
