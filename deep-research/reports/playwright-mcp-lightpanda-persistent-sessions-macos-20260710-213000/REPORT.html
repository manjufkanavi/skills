Playwright MCP + Lightpanda

Persistent Browser Sessions on macOS

Non-Headless Mode • Cross-Restart State • Complete Guide

Two Different MCP Servers

Playwright MCP

Microsoft's official MCP server. Uses Chromium/Firefox/WebKit under the hood. 40+ tools.

npx @playwright/mcp

Lightpanda MCP

Lightpanda's built-in MCP server. Go-based, lightweight browser. 25+ tools.

lightpanda mcp

Plus: Playwright can control Lightpanda via CDP — the hybrid approach.

1. Playwright MCP — Quick Setup

{ "mcpServers": { "playwright": { "command": "npx", "args": ["@playwright/mcp@latest"] } } }

Runs headed (non-headless) by default on macOS — browser window is visible.

npx @playwright/mcp@latest --browser=firefox npx @playwright/mcp@latest --headless # to force headless

2. Session Persistence (Key Feature)

Playwright MCP persists cookies, localStorage, and login state between sessions by default.

macOS profile location:

~/Library/Caches/ms-playwright/mcp-{channel}-profile

Custom profile:

--user-data-dir=/Users/you/playwright-profile

Login once → close server → restart → still logged in. Survives reboots.

3. Explicit State Management

→ browser_storage_state State saved to: auth-state.json → browser_set_storage_state { path: "./auth-state.json" } → browser_navigate { url: "https://app.example.com" } // Already logged in

Or auto-load on startup:

npx @playwright/mcp@latest --caps=storage --isolated --storage-state=./auth-state.json

4. Persistent HTTP Server

Run the MCP server as a long-lived HTTP service:

npx @playwright/mcp@latest --port 8931 --shared-browser-context
{ "mcpServers": { "playwright": { "url": "http://localhost:8931/mcp" } } }

--shared-browser-context shares one browser across multiple connected clients.

5. Lightpanda Native MCP

brew install lightpanda-io/lightpanda/lightpanda lightpanda mcp
{ "mcpServers": { "lightpanda": { "command": "/usr/local/bin/lightpanda", "args": ["mcp"] } } }

25+ tools: goto, click, fill, evaluate, extract, search, markdown, html, etc.

For HTTP with persistence, use supergateway --stateful --sessionTimeout 180000.

6. Playwright + Lightpanda via CDP

Start Lightpanda as a CDP server:

lightpanda serve --host 127.0.0.1 --port 9222 \ --user-data-dir=/Users/you/lightpanda-profile

Connect Playwright:

import { chromium } from 'playwright-core'; const browser = await chromium.connectOverCDP( 'ws://127.0.0.1:9222'); const context = await browser.newContext(); const page = await context.newPage();

7. Auto-Start on macOS Reboot

Create a launchd agent:

~/Library/LaunchAgents/io.lightpanda.cdp.plist Labelio.lightpanda.cdp ProgramArguments /usr/local/bin/lightpanda serve --host127.0.0.1 --port9222 RunAtLoad KeepAlive
launchctl load ~/Library/LaunchAgents/io.lightpanda.cdp.plist
