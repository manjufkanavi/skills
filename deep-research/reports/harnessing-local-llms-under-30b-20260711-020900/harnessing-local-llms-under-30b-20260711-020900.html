Must-Have Skills for Local LLMs

  • Quantization mastery: GGUF (llama.cpp), AWQ, GPTQ, FP16/BF16. GGUF is the universal standard
  • Fine-tuning: LoRA/QLoRA with Unsloth, Axolotl, Hugging Face PEFT, Ollama Modelfile
  • Prompt engineering: System prompts, few-shot, chain-of-thought, ReAct patterns
  • RAG: Chunking, embedding models, vector databases (Chroma, FAISS, Qdrant, Weaviate)
  • Context management: Sliding windows, summary compression, hierarchical attention
  • Infrastructure: Ollama, vLLM, LM Studio, TGI, Docker
  • Agent skills: Function calling, multi-agent orchestration (CrewAI, AutoGen, LangGraph), MCP, evaluation (Promptfoo, DeepEval, RAGAS)

Must-Have MCPs for Local LLMs

  • Model Context Protocol (MCP): Anthropic's open standard for connecting LLMs to external tools and data sources
  • File System MCP: Read/write files, navigate directories, search content
  • Web Search MCP: Brave Search, Tavily, SearxNG for internet access
  • Database MCP: PostgreSQL, SQLite, MongoDB connectors
  • Code Execution MCP: Run Python, JS, shell commands in sandboxed environments
  • Git MCP: Repository operations, diff analysis, commit management
  • Browser MCP: Playwright/Puppeteer for web automation
  • Vector DB MCP: Chroma, Qdrant, Weaviate for RAG workflows
  • GitHub MCP: Issue tracking, PR management, code review
  • Frameworks: Python/TypeScript MCP SDK, LiteLLM, FastMCP

Local LLM Best Practices

  • Model selection: 3B–7B for chat/summarization, 13B–20B for complex reasoning, 24B–32B for domain expertise
  • Prefer recent architectures: Qwen 2.5, Llama 3.1, Mistral Nemo, Phi-3.5
  • Use instruction-tuned variants: Always prefer -Instruct or chat-tuned versions
  • Quantization: Q4_K_M (GGUF) is best quality/size balance (~4.5GB for 7B). Q5_K_M for slightly better quality. Q8_0 for near-lossless
  • GPU offloading: Set n_gpu_layers=-1 in llama.cpp
  • Thread optimization: Set n_threads to physical cores. M4 Mac: use 12–14 threads
  • Prompt engineering: Be explicit, use templates, chain-of-thought, few-shot examples, structured output
  • RAG: Chunk 256–512 tokens, 10–20% overlap, BGE-large embeddings, hybrid search, cross-encoder re-ranking

Handling 260K Context

  • 260K tokens ≈ 200,000 words ≈ 400 pages. Requires smart management
  • Memory cost: KV cache can consume 8–16GB VRAM even for 7B models at full context
  • Sliding Window: Attend only to recent N tokens (32K/64K). Older context summarized. Use --context-length 32768 in llama.cpp
  • Summary Compression: Maintain running summary of earlier sections. Replace old tokens with summary tokens
  • Hierarchical Context: Raw data → extracted facts → summaries → high-level overview. Query relevant layer
  • RAG: Don't load everything. Retrieve only relevant chunks. Chunk 256–512 tokens, BGE embeddings, cross-encoder re-ranking
  • Context Packing: Pack multiple short documents with special token separators
  • Streaming: Process incrementally, maintain state between chunks

Mac Studio M4 Setup for 260K Context

  • Set GPU memory: export OLLAMA_NUM_GPU=99
  • Create custom Ollama model:
ollama pull qwen2.5:32b
cat > Modelfile << 'EOF'
FROM qwen2.5:32b
PARAMETER num_ctx 262144
PARAMETER num_gpu_layers 99
PARAMETER num_thread 14
EOF
ollama create qwen2.5-32b-260k -f Modelfile

vLLM Configuration

from vllm import LLM, SamplingParams

llm = LLM(
    model="Qwen/Qwen2.5-32B-Instruct",
    max_model_len=262144,
    gpu_memory_utilization=0.9,
    tensor_parallel_size=1,
    dtype="float16",
)

sampling_params = SamplingParams(
    temperature=0.7,
    max_tokens=4096,
    top_p=0.95,
)
  • Close other GPU-intensive apps before large context inference
  • Use swap space (SSD as extended RAM) to prevent OOM
  • Monitor with sudo powermetrics --samplers gpu -i 1
  • Batch requests and cache embeddings to avoid recomputation

Context Window Comparison

  • Qwen2.5-3B: 128K max, 64K practical, 2.2 GB VRAM (Q4)
  • Qwen2.5-7B: 128K max, 32K practical, 4.7 GB VRAM
  • Qwen2.5-14B: 128K max, 32K practical, 9.2 GB VRAM
  • Qwen2.5-32B: 128K max, 16K–32K practical, 19 GB VRAM
  • Llama 3.1-8B: 128K max, 32K practical, 5.5 GB VRAM
  • Mistral Nemo 12B: 128K max, 32K practical, 8.5 GB VRAM
  • Gemma 2 9B: 8K max, 8K practical, 6.2 GB VRAM

Practical context limited by VRAM/RAM for KV cache, not just model capability

Key Takeaways

  • Qwen2.5-32B is the best local model under 30B — near-70B quality at deployable size
  • GGUF Q4_K_M is the recommended quantization format for most use cases
  • MCP provides standardized tool integration — essential for agent workflows
  • RAG + vector DBs are critical for domain knowledge beyond model training
  • Context management (sliding window, summary compression, RAG) is essential for 260K+ context
  • Your Mac Studio M4 with 64GB RAM is an excellent platform for local LLM deployment
