1. Growing Organic Traffic

  • Keyword research: Target Karnataka-specific long-tail keywords (500–5K searches/mo) using Ubersuggest, AnswerThePublic, Google Keyword Planner
  • Content strategy: Publish 2,000+ word comprehensive articles, update existing content regularly, build topic clusters
  • On-page SEO: Keyword in URL, H1, first 120 words, H2s, meta title/description, image alt text
  • Off-page SEO: Natural backlinks through quality content, guest posting on Karnataka blogs, local directory listings
  • Technical SEO: Google Search Console, Bing Webmaster Tools, mobile-friendly, fast load speed, SSL, clean URLs
  • Diversify: Don't rely only on Google — explore Bing, DuckDuckGo, Pinterest, email newsletter

3. SEO Wiki — Phase 1: Foundation

  • Domain & Hosting: Configure DNS, SSL, Google Search Console, Bing Webmaster Tools
  • Technical: XML sitemap, robots.txt, canonical URLs, mobile-responsive design, Core Web Vitals
  • Keyword Research: Brainstorm Karnataka topics → find related keywords → identify low-competition long-tails → group into clusters → map to pages
  • Keyword Categories: Karnataka news, Bangalore tech, Karnataka tourism, Kannada culture, Karnataka food, Karnataka education, Karnataka festivals

3. SEO Wiki — Phase 2: Content

  • Article structure: H1 with keyword → intro in 120 words → H2s with related keywords → 2,000+ words → optimized images → internal links → FAQ section
  • Content types: Listicles, guides, reviews, how-to, news/opinion, comparisons
  • On-page checklist: Unique meta title (50–70 chars), meta description (150–160 chars), keyword in URL/H1/H2s, internal links (3–5), schema markup
  • Off-page: Shareable infographics, guest posts, local directory listings, community engagement
  • Monitoring: Google Search Console for impressions/CTR/position, Google Analytics for traffic sources, update old posts quarterly

3. SEO Wiki — Modern Best Practices

  • EEAT matters: Experience, Expertise, Authoritativeness, Trustworthiness — Google prioritizes content demonstrating these
  • First-hand experience: Personal stories, photos, local insights that AI can't replicate
  • Content updates: Updating old posts is the fastest way to gain traffic — refresh stats, expand sections, add FAQs
  • Topic clusters: Cover related subjects within a niche to build topical authority
  • Cornerstone content: Long definitive guides that serve as hubs for related articles
  • Internal linking: Strategic links help search engines discover content and distribute authority

4. Subdomain Configuration

  • DNS: Add wildcard A record or CNAME pointing to your hosting provider
  • Netlify: Add subdomains in Domain management → handles wildcard automatically
  • Vercel: Project settings → Domains → add each subdomain separately
  • Cloudflare Pages: Pages → Settings → Domains → add root + subdomains
  • GitHub Pages: Each subdomain needs separate repo + CNAME file

Each subdomain is treated as a separate website by Google — build authority independently

6. User Signup & Comments

  • Firebase Auth + Firestore: Free tier, email/Google login, comments stored in Firestore — best for custom experience
  • Disqus: Easiest — just embed a script, built-in spam filtering, social login
  • Utterances: Free, uses GitHub Issues as comments — great for dev blogs
  • Commento: Open-source, self-hosted commenting system
  • Newsletter Signup: Mailchimp (free 500 contacts), ConvertKit (free 1K subs), Beehiiv, Substack

Recommendation: Firebase for custom signup + comments, Mailchimp/ConvertKit for newsletter
