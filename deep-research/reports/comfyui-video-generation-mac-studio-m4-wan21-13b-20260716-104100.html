ComfyUI Video Generation on Mac Studio M4

Setting up Wan 2.1 1.3B with MLX for local video generation

Press → or Space to navigate

Hardware & Requirements

  • Mac Studio M4 with 64GB unified memory
  • Minimum 1TB free storage
  • Python 3.10+ via venv or uv
  • ComfyUI + ComfyUI-WanVideoWrap
  • Wan 2.1 1.3B FP8 model (~8.19 GB)

Installation Steps

git clone https://github.com/comfyanonymous/ComfyUI.git cd ComfyUI python3 -m venv venv && source venv/bin/activate pip install -r requirements.txt # Install Wan Video nodes cd custom_nodes git clone https://github.com/kijai/ComfyUI-WanVideoWrap.git # Download model huggingface-cli download Wan-AI/Wan2.1-T2V-1.3B \ --local-dir ~/MLXModels/Wan-AI/Wan2.1-T2V-1.3B

Memory Management

64GB RAM constraint — MLX LLM and ComfyUI cannot run simultaneously

  • Qwen3.6-35B-A3B-4bit: ~8–12GB
  • Wan 2.1 1.3B: ~8–10GB
  • System overhead: ~8–12GB

Strategy: Unload MLX → Run ComfyUI → Free ComfyUI → Reload MLX

API Lifecycle

# 1. Unload MLX model curl -X POST http://localhost:8095/v1/models/unload \ -d '{"model":"mlx-community/Qwen3.6-35B-A3B-4bit"}' # 2. Submit workflow curl -X POST http://localhost:8188/prompt \ -d '{"prompt":{...}}' # 3. Free ComfyUI memory curl -X POST http://localhost:8188/free # 4. Reload MLX model curl -X POST http://localhost:8095/v1/models/load \ -d '{"model":"mlx-community/Qwen3.6-35B-A3B-4bit"}'

Performance Optimization

  • FP8 quantization — 40% VRAM reduction vs BF16
  • CausVid LoRA — reduces steps from 30 to 20
  • VAE tiling — 256×256 tiles for lower peak memory
  • Frame trimming — remove 1-4 frames from edges

~4 min for 5s 480P video (without optimization)

Headless Execution

# Start ComfyUI python3 main.py --port 8188 --listen 0.0.0.0 --force-fp16 # Monitor via WebSocket python3 -c " import asyncio, websockets, json async def m(): async with websockets.connect('ws://localhost:8188/ws') as ws: async for msg in ws: d = json.loads(msg) if d.get('type') == 'progress': print(f'{d[\"data\"][\"value\"]}/{d[\"data\"][\"max\"]}') asyncio.run(m()) "

Troubleshooting

  • OOM errors: Reduce resolution, frames, enable VAE tiling
  • Black output: Increase CFG to 7-8, steps to 30-35
  • Slow generation: Use FP8, apply CausVid LoRA, reduce steps
  • Glitchy frames: Trim 1-4 frames from start/end

Key Takeaways

  • Wan 2.1 1.3B is the most accessible video model for Mac Studio M4
  • Sequential unload/load cycle is mandatory for 64GB RAM
  • FP8 + CausVid LoRA cuts generation time by ~40%
  • REST API + WebSocket monitoring enables full automation
  • 832×480 at 16fps is the sweet spot for quality/speed
