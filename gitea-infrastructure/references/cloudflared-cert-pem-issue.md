# Cloudflare Tunnel — cert.pem Issue

## Problem

After upgrading or reconfiguring a Cloudflare Tunnel, `cloudflared tunnel list` (and sometimes the tunnel itself) fails with:

```
ERR Cannot determine default origin certificate path. No file cert.pem in [~/.cloudflared ~/.cloudflare-warp ~/cloudflare-warp /etc/cloudflared /usr/local/etc/cloudflared]. You need to specify the origin certificate path by specifying the origincert option in the configuration file, or set TUNNEL_ORIGIN_CERT environment variable originCertPath=
Error locating origin cert: client didn't specify origincert path
```

## Root Cause

Cloudflare Tunnel has **two** credential files:

| File | Purpose | Location | Generated by |
|---|---|---|---|
| `iacgenie-tunnel.json` | Tunnel credentials (auth token) | `/etc/cloudflared/` | `cloudflared tunnel create` |
| `cert.pem` | Origin TLS certificate | `~/.cloudflared/` or `/etc/cloudflared/` | `cloudflared tunnel login` |

The tunnel can operate with only the credentials file, but the CLI (`tunnel list`, `tunnel info`) and some newer versions of cloudflared **require** the origin cert for certain operations. If `cert.pem` is missing, CLI commands fail with the error above.

## Fix

### Option 1: Re-run `cloudflared tunnel login` (RECOMMENDED)

```bash
cloudflared tunnel login
```

This generates a new `cert.pem` in `~/.cloudflared/` or `/etc/cloudflared/`. The tunnel service will continue to work without restart since it only needs `iacgenie-tunnel.json`.

### Option 2: Specify cert path in config

Add to `/etc/cloudflared/config.yml`:
```yaml
origincert: /path/to/cert.pem
```

### Option 3: Set environment variable

In the systemd service file:
```ini
[Service]
Environment=TUNNEL_ORIGIN_CERT=/etc/cloudflared/cert.pem
```

## Diagnosing Tunnel Issues

```bash
# 1. Is the service running?
systemctl status cloudflared

# 2. Are credentials present?
ls -la /etc/cloudflared/iacgenie-tunnel.json /home/mkanavi/.cloudflared/cert.pem

# 3. Can CLI determine tunnel?
cloudflared tunnel list 2>&1

# 4. Tunnel connection details
cloudflared tunnel info iacgenie-tunnel 2>&1

# 5. Recent logs
journalctl -u cloudflared --since "1 hour ago" -n 30
```

## Legacy Migration (argotunnel.json → cert.pem)

Older Cloudflare Tunnel setups used `argotunnel.json` (the "argotunnel" format). Newer versions use the `--login` flow which generates both:
- `iacgenie-tunnel.json` — tunnel credentials (same format, different name)
- `cert.pem` — origin certificate

If you see `argotunnel.json` but no `cert.pem`, the tunnel was set up with the old method. Run `cloudflared tunnel login` to generate the cert:

```bash
# Old format
ls ~/.cloudflared/argotunnel.json

# Fix
cloudflared tunnel login

# Verify new cert exists
ls ~/.cloudflared/cert.pem
```
