# UX Design — Presentation Decks

## Overview

8 minimalist presentation decks across 8 distinct color and font themes.
All designs are **fully responsive** (phone → laptop → desktop) and **A4 print-friendly** with proper borders, corner marks, and page-break styling.

## Responsive Design

Every page uses `clamp()` for fluid typography and spacing:
- **Phone** (<600px): Stacked single-column layout
- **Tablet** (600-1024px): Two-column grid
- **Desktop** (1024px+): Three-column grid, max-width 210mm (A4)
- **Print**: Full A4, no shadows, proper page breaks

## Interactive Features

- **Slide navigation** — Prev/Next buttons in fixed bottom bar
- **Keyboard controls** — Arrow keys for slides, Home/End
- **Print button** — One-click PDF export
- **Theme selector** — Landing page to pick any theme

## Print to PDF

1. Open any HTML file in Chrome/Safari
2. Press `Cmd+P` / `Ctrl+P`
3. Set destination to **"Save as PDF"**
4. Set paper size to **A4**
5. Margins: **None** (the page CSS handles margins)
6. Enable **Background graphics**
7. Click **Save**
